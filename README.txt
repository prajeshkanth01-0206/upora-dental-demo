UPORA DENTAL CLINIC — WEBSITE DEMO
==================================

HOW TO VIEW
1. Extract the ZIP folder.
2. Double-click index.html to open it in a modern browser.
3. For a local server, open this folder in VS Code and use Live Server.

FILES
- index.html  Main page and content
- styles.css  Responsive styling, blue/white design, animations and mobile layouts
- script.js   Smooth anchor navigation, active section links, sticky/hide-on-scroll header,
              reveal animations, mobile navigation and demo appointment form behaviour

DEMO NOTES — PLEASE READ BEFORE SHOWING/PUBLISHING
- This is an original dental-clinic concept for Upora, inspired by common modern dental
  website patterns. It does not copy the source site's source code or exact assets.
- The Chennai location, phone number, opening hours, team profiles, testimonials and rating
  are illustrative placeholders. Replace them with verified details before a real launch.
- The appointment form only prepares a draft email on the visitor's device; it does not
  store data or contact a clinic automatically.
- Photos are loaded from Unsplash via remote image URLs, so internet access is needed for
  those images. Google Fonts are also loaded remotely.
- The website is plain HTML, CSS and vanilla JavaScript; no build step or npm packages are
  required.
